How to install

  1. Tap the green button above (on the phone).
  2. Android may warn that the file is from an unknown source — choose Download anyway, then Install and allow Install unknown apps for your browser if asked.
  3. Open AlignTasks and sign in with your email + password.
Already have an older AlignTasks installed? If Android refuses to install with “App not installed / signature mismatch”, uninstall the old app first, then install this one. Your tasks live in the cloud, so nothing is lost.
