Persist an imported Drive token into .env as well

The data-folder token file is what candlGdrive reads first, so it wins today.
But .env still held the older, dead refresh token - if the data file were
ever lost (fresh checkout, rebuilt host) that dead value would come back and
the banner would return. The import endpoint now rewrites both names in .env
atomically while it writes the token file.
