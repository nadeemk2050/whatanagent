Point the Drive banner at a self-service fix page

Pressing "Re-authorize Google Drive" opened the raw Google consent URL, which
answers with "Error 400: redirect_uri_mismatch" whenever the OAuth client has
not been told about this host - a dead end with no explanation.

- GET /candl/api/gdrive/help: styled page showing the live connection state,
  the EXACT redirect URI this server sends (copy button friendly), the two
  Google Cloud steps, and then an "Authorise now" button. Server-side only, so
  it works even while the token is dead.
- /gdrive/status returns helpUrl; the dashboard banner now links there and says
  what the button does.
