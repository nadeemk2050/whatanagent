Keep the section on the cloud store, and never probe a records API

Served at /proforma the app used to find its own host answering /warmup and
concluded that a full records backend existed, which would have run the legacy
"backfill orders.db to Firestore" path against a service that only stores file
bytes. It now treats /proforma as cloud mode from the start, so records stay in
the browser SQLite + Firestore and the stray /api/warmup 404 disappears.
